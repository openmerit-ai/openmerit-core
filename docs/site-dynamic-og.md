# Page sharing images

The optional documentation-page image template is retired with the unpublished docs website shell in November 2026 source. Its generator and exclusive workshop background are no longer needed. Retained pages use the existing shared `site/assets/openmerit-og-v1.png`; Scout's separate social-image builder remains.

Do not regenerate or replace the shared artwork as part of cleanup. Its provenance is recorded in [site OG image notes](site-og-image.md). A local policy/memo build does not publish assets or change social-platform caches; release only through the [deployment workflow](site-deployment.md) after approval.
