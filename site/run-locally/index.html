ScoutMemo

Choose an AI model for your code without your code going through OpenMerit

The OpenMerit CLI runs on your machine, with your own keys and no OpenMerit account or service in the loop. Running it yourself is free.

Where your code and data go

  • To the model provider you chose for the harness, to read and review code: Anthropic through Claude Code, OpenAI through your ChatGPT sign-in, or your API provider. Snippets are redacted for anything shaped like a key.
  • To the candidate endpoints you configured: eval inputs only, during evals you approved.
  • On your machine: run history and each run’s progress, never with keys or dataset contents.
  • To OpenMerit: anonymous usage data only, such as command names, success, duration and versions, never code, arguments, paths or model IDs. Turn it off with OPENMERIT_TELEMETRY=0 or DO_NOT_TRACK=1.

Never in your request path

OpenMerit picks a model ahead of time and changes the model name in your code after you approve. Your app keeps calling its provider directly, so if OpenMerit stops, nothing in production changes. See OpenMerit vs routers and gateways.

Requirements

  • Node.js 22.19 or newer.
  • Linux (x64 and arm64, tested in CI) or macOS on Apple silicon. Windows isn’t supported.
  • About 660 to 790 MB of disk space.

What it costs

  • OpenMerit on your machine: free.
  • Your own model spend: evals run on your keys within a budget you set ($10 per run by default). The harness runs on your Claude or ChatGPT plan, or your API key.
  • OpenMerit Cloud: we run the reviews and evals for you. For pricing, contact us.

Try it

npm install -g openmerit
cd your-repo && openmerit setup && openmerit scout
