    Connect Langfuse

    Bring your own evals. Scout reads aggregate scores for your account only—never trace inputs, outputs or score comments.

    1. Open your Langfuse project → Settings → API Keys → Create new API keys.
    2. Select Viewer under Permissions. Keep your application's tracing keys unchanged.
    3. Copy the new key pair below. The secret is shown only once by Langfuse.
    Score and model mappings

    You can connect the key first and configure mappings by disconnecting and reconnecting later. Each scored trace must be tagged with the prefix below plus its experiment ID. Untagged experiments are not imported. Mapping guide

    Each entry: metric, modelKey, task, traceName, level (task/agent/environment), kind (quality/usd/seconds), higherIsBetter (true/false).

    Map experiment metadata values to exact Scout catalogue model or endpoint IDs. Never put record IDs or secrets in mappings.

    Keys are encrypted. Aggregates expire after 90 days; an inactive evaluation account is erased after 90 days. Disconnect deletes the key and imported aggregates, not past conversations. Data policy
