Compare and pick LLMs for your app from inside Claude Code or Codex

OpenMerit is an MCP server. openmerit setup registers it with Claude Code and Codex when either CLI is installed. Then you ask your coding agent to find a cheaper model for a call in your app, and it runs the same workflow as the CLI.

How it works in your agent

  • The openmerit_scout tool returns questions instead of prompting: which task, approve this eval, raise the budget, apply this change. Your agent asks you, then passes your answers back.
  • A run started in the terminal can continue in your agent, and the other way round.
  • openmerit_status and openmerit_history are read-only.

What powers the reasoning

OpenMerit’s harness, built on Pi, reviews the code and writes the evals. It can use your Claude login through Claude Code, a ChatGPT Plus or Pro sign-in for Codex models, or an API key. The evals run on the candidate endpoints you choose, with their own keys.

Other MCP clients and OpenMerit Cloud

If neither CLI is installed, setup prints the stdio command to register with another client. For OpenMerit Cloud, add https://openmerit.ai/mcp as an HTTP MCP server instead.

Try it

Running OpenMerit on your machine is free: npm install -g openmerit, then openmerit setup. For OpenMerit Cloud pricing, contact us.
